# History

In January 2024 Haier Europe sent the original author, [Andre0512](https://github.com/Andre0512), a takedown notice for this integration. These two documents are his account, kept as he wrote them:

- [takedown_faq.md](takedown_faq.md) — the notice, his replies, and Haier's response
- [takedown_timeline.md](takedown_timeline.md) — how the community reacted, day by day

The integration was later continued by [mmalolepszy/hon-revived](https://github.com/mmalolepszy/hon-revived), which this repository builds on.
